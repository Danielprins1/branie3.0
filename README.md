# BRANIE

Website van BRANIE, gebouwd met [Next.js](https://nextjs.org) en gehost op Vercel.

## Lokaal draaien

```bash
npm install
npm run dev
```

Open daarna http://localhost:3000.

## Deployment

De repository is gekoppeld aan Vercel:

- elke push naar `main` gaat automatisch live (production);
- elke andere branch / pull request krijgt een eigen preview-URL.
